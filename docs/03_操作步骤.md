# 03 操作步骤

## 数据准备

### 下载数据集

``
python code/download_data.py
``

数据集 `alpaca-gpt4-data-zh.json` 共 48,818 条中文指令样本，每条格式：

```json
{
  "instruction": "请解释什么是机器学习",
  "input": "",
  "output": "机器学习是人工智能的一个分支..."
}
```

### 数据切分

`train_lora.py` 内部按顺序取前 5000 条作为训练集，取最后 200 条作为 held-out 评估集（disjoint split）。这样做的目的是：

- 控制数据规模（5000 条足够让 0.5B 模型在 3 epoch 内收敛）
- 保证训练与评估样本完全不重叠

## 训练

### 零样本基线评估

不训练，直接评估基础模型的困惑度：

``
python code/eval_lora.py --model hf_cache/Qwen2.5-0.5B --data datasets/alpaca_gpt4_data_zh.json --n_eval 200 --output output_05/zero_eval.json
``

对 1.5B 同理：

``
python code/eval_lora.py --model hf_cache/Qwen2.5-1.5B --data datasets/alpaca_gpt4_data_zh.json --n_eval 200 --output output_15/zero_eval.json
``

### LoRA 微调

``
python code/train_lora.py \
  --model hf_cache/Qwen2.5-0.5B \
  --data datasets/alpaca_gpt4_data_zh.json \
  --mode lora \
  --dtype bf16 \
  --epochs 3 \
  --batch 1 \
  --grad_accum 8 \
  --lr 2e-4 \
  --max_len 512 \
  --output output_05_lora
``

训练过程：

- LoRA 仅训练 0.88% 参数（4,399,104 / 498,431,872）
- 每 20 step 写一次 `progress.txt`
- 每 epoch 保存 `history.json` 与生成样本 `samples.json`

### 全量微调

``
python code/train_lora.py \
  --model hf_cache/Qwen2.5-0.5B \
  --data datasets/alpaca_gpt4_data_zh.json \
  --mode full \
  --dtype bf16 \
  --epochs 2 \
  --batch 1 \
  --grad_accum 8 \
  --lr 5e-5 \
  --output output_05_full
``

> 全量微调必须用 bf16；fp16 下梯度会溢出（NaN）。

## 检查输出

训练完成后 `output_05_lora/` 应包含：

| 文件 | 含义 |
|------|------|
| history.json | 每个 epoch 的 train/eval loss |
| samples.json | 生成样本与参考对比 |
| progress.txt | 最后一次训练进度 |
| lora_weights/ | LoRA 权重（仅 LoRA 模式） |
| full_weights.pt | 全量微调权重（仅 full 模式） |
