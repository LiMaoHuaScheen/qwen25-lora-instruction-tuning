# 02 环境搭建

## 硬件环境

| 项目 | 配置 |
|------|------|
| GPU | NVIDIA GeForce RTX 5060 Laptop (8GB VRAM) |
| CUDA | 12.8 |
| 操作系统 | Windows 11 |

> RTX 5060 支持 bf16（Blackwell 架构），全量微调 0.5B 模型在 bf16 下可正常训练。
> fp16 下全量微调会出现梯度溢出（NaN loss），需切换为 bf16。

## 安装步骤

### 1. 安装 PyTorch（CUDA 版本）

从阿里云镜像下载（中国大陆加速）：

``
pip install torch torchvision --index-url https://mirrors.aliyun.com/pytorch-wheels/cu128/
``

或从 PyPI：

``
pip install torch --index-url https://mirrors.aliyun.com/pypi/simple/
``

### 2. 安装其余依赖

``
pip install transformers peft accelerate datasets matplotlib --index-url https://mirrors.aliyun.com/pypi/simple/
``

### 3. 验证安装

``
python -c "import torch; print(f'torch {torch.__version__} / cuda {torch.cuda.is_available()}')"
``

## 模型下载

### 方法一：HuggingFace CLI（推荐，支持断点续传）

设置 hf-mirror.com 镜像（中国大陆可访问）：

``
# Windows PowerShell
$env:HF_ENDPOINT = "https://hf-mirror.com"

# Linux/Mac
export HF_ENDPOINT=https://hf-mirror.com
``

下载模型：

``
huggingface-cli download Qwen/Qwen2.5-0.5B --local-dir hf_cache/Qwen2.5-0.5B
huggingface-cli download Qwen/Qwen2.5-1.5B --local-dir hf_cache/Qwen2.5-1.5B
``

### 方法二：直接 curl（断点续传）

``
mkdir -p hf_cache/Qwen2.5-0.5B
curl -L -C - -o hf_cache/Qwen2.5-0.5B/model.safetensors \
  https://hf-mirror.com/Qwen/Qwen2.5-0.5B/resolve/main/model.safetensors
``

需下载的小文件（config.json, tokenizer.json, vocab.txt 等）可从同一 URL 模式手动下载。

## 常见问题

### Q: HuggingFace 直接访问超时

A: 设置 `HF_ENDPOINT=https://hf-mirror.com` 使用镜像。

### Q: 显存不足（OOM）

A: 0.5B 模型 LoRA 微调约需 4GB 显存，全量微调约需 5-6GB。如不足，可尝试：
- 降低 `max_len`（默认 512）
- 使用 `--dtype bf16`（fp16 会溢出）
- 关闭其他 GPU 进程

### Q: 全量微调 loss 变成 NaN

A: 使用 `--dtype bf16`，RTX 50 系列支持 bf16，避免 fp16 梯度溢出问题。
