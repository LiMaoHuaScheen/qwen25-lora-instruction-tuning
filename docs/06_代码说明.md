## train_lora.py

### 功能

统一处理三种模式（`--mode`）：

1. **zero**：仅评估基础模型困惑度（等价于 `eval_lora.py` 的零样本模式）
2. **lora**：使用 PEFT LoRA 微调，仅训练 <1% 参数
3. **full**：全量微调，所有参数参与训练

### 关键参数

| 参数 | 默认值 | 说明 |
|------|-------|------|
| `--model` | — | 模型路径（本地目录或 HuggingFace ID） |
| `--data` | — | 训练数据 JSON 文件路径 |
| `--mode` | `lora` | `zero` / `lora` / `full` |
| `--dtype` | `bf16` | 精度（必须 bf16 用于全量微调） |
| `--epochs` | 3 | 训练轮数 |
| `--batch` | 1 | 每卡 batch size |
| `--grad_accum` | 8 | 梯度累积步数（等效 batch = 8） |
| `--lr` | 2e-4 | 学习率（全量微调建议 5e-5） |
| `--max_len` | 512 | 最大序列长度 |
| `--output` | — | 输出目录 |

### LoRA 配置

```python
LoraConfig(
    r=8,                       # 低秩矩阵秩
    lora_alpha=16,             # 缩放因子
    target_modules=[
        "q_proj", "k_proj", "v_proj", "o_proj",  # 注意力层
        "gate_proj", "up_proj", "down_proj"      # FFN 层
    ],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)
```

### 训练细节

- **优化器**：AdamW（weight_decay=0.01）
- **学习率调度**：线性 warmup（3% 总步数）+ 线性衰减
- **梯度裁剪**：max_norm=1.0
- **标签掩码**：将 PAD token 的 label 设为 -100（不计算损失）
- **精度**：bf16（fp16 会溢出）

### 输出

``
output_dir/
  history.json       # 每个 epoch 的 train/eval loss
  progress.txt       # 每 20 step 更新进度
  samples.json       # 生成样本与参考对比
  lora_weights/      # LoRA 权重（仅 LoRA 模式）
  full_weights.pt    # 全量微调权重（仅 full 模式）
```

## eval_lora.py

### 功能

1. 加载模型（可选 LoRA 权重）
2. 在 held-out 样本上计算困惑度
3. 生成若干样本与参考对比

### 关键参数

| 参数 | 说明 |
|------|------|
| `--model` | 基础模型路径 |
| `--lora` | LoRA 权重目录（可选） |
| `--data` | 评估数据 JSON 路径 |
| `--device` | `cuda` 或 `cpu` |
| `--max_len` | 最大序列长度 |
| `--n_eval` | 评估样本数（默认 200） |
| `--output` | 输出 JSON 文件路径 |

## plot_lora.py

### 功能

读取 `output_lora/result_summary.json` 与各训练目录的 `history.json`，生成：

1. **ppl_comparison.png**：4 方案 PPL 柱状对比图
2. **loss_curve.png**：0.5B LoRA 与全量微调训练/验证损失曲线（子图）

### 关键依赖

- matplotlib（Agg 后端，无 GUI）
- 使用英文标签避免中文字体缺失问题

## download_data.py

### 功能

使用 `huggingface_hub.hf_hub_download` 下载 `llm-wizard/alpaca-gpt4-data-zh` 数据集。

### 端点配置

默认使用 `HF_ENDPOINT=https://hf-mirror.com` 镜像（中国大陆可访问）。可通过环境变量覆盖：

``
export HF_ENDPOINT=https://huggingface.co
```

## 复现实验

### 最小复现（约 30 分钟）

``
# 1. 下载数据（1 分钟）
python code/download_data.py

# 2. 零样本评估（5 分钟）
python code/eval_lora.py --model hf_cache/Qwen2.5-0.5B --data datasets/alpaca_gpt4_data_zh.json --n_eval 200 --output output_05/zero_eval.json

# 3. LoRA 微调（20 分钟）
python code/train_lora.py --model hf_cache/Qwen2.5-0.5B --data datasets/alpaca_gpt4_data_zh.json --mode lora --dtype bf16 --epochs 1 --output output_05_lora

# 4. 可视化
python code/plot_lora.py
```

参见 [03_操作步骤.md](03_操作步骤.md)。

## 已知问题

1. **fp16 溢出**：全量微调在 fp16 下梯度溢出，必须用 bf16
2. **生成文本中的零宽空格**：部分生成文本包含 U+200B，写入 JSON 时需指定 `encoding="utf-8"`
3. **长任务中断**：Windows 睡眠会杀死后台 Python 进程，建议用 `Start-Process` 启动独立 .bat 文件
